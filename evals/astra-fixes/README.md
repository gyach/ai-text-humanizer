# Прогон исправлений по Astra

Это артефакты выполнения моделей и независимого смыслового ревью, а не автоматически исполняемый модельный benchmark. В поставку плагина они не входят.

- `cases.json`: девять новых заданий и смысловые критерии. `make_cases.py` воспроизводит синтетический корпус, включая документ на 3 034 слова с 40 участками.
- `baseline-skill/` и `candidate-skill/`: точные снимки инструкций до и после исправления, для воспроизводимости после следующих изменений.
- `baseline.json`: ответы предыдущей версии на девять новых заданий.
- `candidate.json`: ответы исправленной версии на прежние 14 и новые девять заданий.
- `review-target.md`: реальный синтетический файл для режима review. Его итоговое содержимое сверяется с входом; это не полный журнал вызовов инструментов.
- `review.md`: независимая оценка Astra, включая закрытие трёх замечаний. `run.json` привязывает инструкции, входы, ответы и ревью хешами.

Генераторам передавались задача и текст без использования criteria для составления ответа. Смысловые критерии предназначены проверяющему. Предыдущие ответы и отчёты генератор исправленной версии не использовал.

Повторение: сохранить снимок проверяемого скилла, выполнить каждый task/text с этим снимком, записать точные ответы по id, передать независимому проверяющему входы/выходы/criteria, сверить изменяемые файлы, сохранить хеши. Не сводить оценку к наличию слов, снижению объёма или совпадению с эталонной формулировкой.

Случаи охватывают область действия условий и «только», «не обязан»/«обязан не», необходимые и достаточные условия, обманчивое имя файла, локальные регистры, смешанный язык, MDX, удалённые дубли и уникальные исключения. Они не доказывают устойчивость на любом размере документа, в любом языке и на любой модели. Точные параметры генерации не зафиксированы; результаты не доказывают измеренный выигрыш над baseline. Фактическая установка в платформы не выполнялась.
