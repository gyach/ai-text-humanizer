# Источники и совместимость

Проверено 1 ноября 2026 года. Формат пакета и доступность интерфейса установки — разные вещи. Пакеты собраны локально; установка в аккаунты пользователя не выполнялась.

## Исходные наработки

Пользователь предоставил два локальных скилла:

- `hrl-humanizer`: SKILL.md, references/pattern-catalog.md и references/utr-profile.md. Использованы выбор локального регистра, сохранность информации в обе стороны, работа с причинами и последствиями, самостоятельность требований, минимальная достаточная правка.
- `docs-humanizer`: SKILL.md. Использованы анализ ответственности, терминологической согласованности, неоднозначных ссылок и машинных штампов.

Это переработка принципов в общий жанровый скилл. Не перенесены пути проектов, персональные данные, корпоративные глоссарии и оркестраторы, требования к моделям, история внутренних прогонов и тесты, привязанные к чужому репозиторию. Профиль УТР не используется как заявление о соответствии ГОСТу. Примеры неизвестных API-кодов и лимитов не становятся фактами редактируемого документа.

## Официальные форматы

- [OpenAI: Package your plugin](https://developers.openai.com/plugins/build/plugins): переносимый корневой `plugin.json` с Agent Plugins schema; общая папка `skills/`; `.codex-plugin/plugin.json` — поддерживаемый fallback. В пакете нет `extensions.com.openai` в корневом манифесте, поэтому OpenAI-оформление берётся из fallback. Не нужно объединять конфликтующие определения.
- [OpenAI: Submit your Claude Code plugin](https://developers.openai.com/plugins/guides/submit-claude-plugin): skills-only пакет может содержать `.claude-plugin/plugin.json` и `skills/<name>/SKILL.md`. Загрузка через портал и последующее ревью — отдельный процесс, не выполненный сборкой.
- [ChatGPT: Skills](https://help.openai.com/en/articles/20001066-skills-in-chatgpt): прямой upload отдельного скилла через Plugins → Skills → Create. Доступность зависит от продукта, аккаунта и настроек workspace.
- [OpenAI: Build skills](https://learn.chatgpt.com/docs/build-skills): SKILL.md с метаданными и поддерживающими файлами. Для локального Codex используются `.agents/skills/` проекта и `~/.agents/skills/` пользователя; подключение плагина и установка одного скилла — альтернативы.
- [Claude: Plugin manifest reference](https://code.claude.com/docs/en/plugins-reference): манифест `.claude-plugin/plugin.json`, стандартная папка `skills/` в корне. Не дублируем её дополнительным `skills`-путём.
- [Claude: Plugins overview](https://code.claude.com/docs/en/plugins): разработка без marketplace через `--plugin-dir`; возможности разных поверхностей отличаются.
- [Claude: Use skills](https://support.claude.com/en/articles/12512180-use-skills-in-claude): самостоятельный skill ZIP содержит папку скилла и загружается через Customize → Skills. Может требоваться включённая возможность выполнения кода и создания файлов на стороне продукта, хотя сам humanizer не запускает код.

Манифесты не объявляют авторство сторонних компаний, фиктивные сайты, поддержку, политику приватности или лицензию на исходные корпоративные материалы. Для публикации необходимые поля карточки заполняются отдельно.
