# Проверка версии 0.1.1

Дата: 1 ноября 2026 года. Проверки выполнены локально на macOS с Python 3.9.6. Установка в Claude/ChatGPT и публикация в их каталогах не выполнялись.

## Исправления по независимому аудиту

1. В примере сокращения сохранено «В этом случае»: отказ и запрос доступа явно связаны с неуспешной проверкой. Добавлено пояснение об области действия условий, отрицаний и различии необходимых и достаточных условий.
2. Из документов поставки удалены персональные пути и внутренние деревья исходных проектов. Проверка известных признаков локального контекста теперь применяется к каждому файлу обоих архивов, включая README, JSON и YAML. Это проверка конкретных признаков, а не универсальная классификация конфиденциальности.
3. Локальные Markdown-ссылки проверяются по составу каждого ZIP. Файл, существующий в репозитории, но отсутствующий в поставке, больше не считается доступным. Отдельный скилл не может зависеть от документа, доступного только в полном плагине. Проверка выполняется до записи архивов.

## Структура и сборка

Из исходного репозитория, где доступны scripts/ и tests/:

```sh
python3 -m unittest discover -s tests -v
python3 scripts/package.py
```

Прошли 6 интеграционных тестов: реальная сборка из другого рабочего каталога; отказ на существующем, но неупакованном справочнике; отказ на локальном контексте в каждом из пяти типов поставляемых документов; reference-style ссылка на непоставляемый документ; зависимость самостоятельного скилла от README полного плагина; другие домашние пути и известные внутренние названия. Часть тестов содержит несколько независимых входов.

Штатный quick_validate.py из skill-creator вернул «Skill is valid!». Вспомогательный PyYAML для него установлен во временный каталог; в сборку и runtime плагина эта зависимость не входит. Метаданные agents/openai.yaml также разобраны YAML-парсером.

Astra независимо повторила тесты и сборку. Оба ZIP прочитаны, файлы сверены с исходниками; прежние персональные пути и внутренние деревья в поставке отсутствуют. Сборка использует явный список ресурсов и стандартную библиотеку Python 3.9+.

## Поведение

Для исправленной версии получены 23 точных ответа: 14 прежних и 9 новых сложных заданий. Независимая смысловая проверка Astra приняла все 23 ответа. Новые случаи проверяют:

- Успешную и неуспешную ветви, связь условия и результата.
- «Не обязан» и «обязан не», несколько отрицаний, необходимые условия и область действия «только».
- Письмо в файле с обманчивым именем и смешанные регистры без подсказок в заголовках.
- Русскую прозу рядом с английским текстом, техническими литералами, таблицей и MDX.
- Режим review реального синтетического файла: итоговое содержимое совпадает с исходным. Хеш не заменяет полный журнал инструментов.
- Документ на 3 034 слова: проверены все 40 соответствий маршрутов по разделам, общий смысл каждого повторяющегося блока, удалённые повторы, уникальные исключения, запрет отгрузки и отдельное разрешение владельца качества.

Девять сложных заданий также выполнены с предыдущей версией инструкций. Эти единичные прогоны не доказывают устойчивый выигрыш; точные параметры генерации не зафиксированы. Исходные ответы, критерии, повторное ревью и хеши сохранены в исходном репозитории вне поставки, в evals/astra-fixes/. Предыдущий аудит версии 0.1.0 сохранён локально вне публичной поставки.

## Границы результата

Это проверка структуры поставки и конкретных смысловых ответов. Фактический импорт в Claude и ChatGPT, платформенное сканирование, автоматическое обнаружение скилла и устойчивость на документах произвольного размера не проверялись. Публикационная карточка отдельно не оформлялась. Официальные форматы и источники перечислены в [sources.md](sources.md).
