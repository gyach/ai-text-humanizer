# AI Text Humanizer

Плагин с одним адаптивным скиллом `humanize-text`: помогает писать и редактировать естественный русский текст, сохраняя смысл и нормы выбранного документа. Поддерживает спецификации, ADR, API-документацию, инструкции, письма, статьи, исследования, публичные и юридические тексты. В смешанных документах учитывает назначение отдельных фрагментов.

Скилл работает при написании, редактировании и ревью. Он сохраняет факты, условия, обязательность, технические литералы и голос автора. Английские фрагменты первая версия оставляет без изменений. Для работы скилла не нужны скрипты, MCP-сервер, ключи или внешние сервисы.

## Использование

После подключения скилла сформулируйте задачу обычным языком, например:

- «Очеловечь эту спецификацию. Сохрани REQ-ID и обязательность требований».
- «Напиши письмо коллеге по этим тезисам, на ты, без канцелярита».
- «Проверь статью на машинные штампы; верни только замечания, файл не меняй».
- «Отредактируй runbook.md, сохрани команды и автоматические действия сервиса».

Тип документа можно указать явно. Если он не указан, скилл выбирает профиль по задаче и содержанию. Ясный текст может остаться без изменений. Скилл не обещает обход детекторов ИИ и не заменяет проверку фактов или юридическую экспертизу.

## Подключение

### Claude Code

Из корня распакованного плагина, для локального запуска без установки:

```sh
claude --plugin-dir .
```

В открытой сессии:

```text
/ai-text-humanizer:humanize-text Очеловечь переданный текст, сохрани смысл.
```

Манифест Claude находится в `.claude-plugin/plugin.json`; стандартная папка `skills/` обнаруживается автоматически. Если нужен только скилл, распакуйте skill ZIP и поместите папку `humanize-text` в `.claude/skills/` проекта или `~/.claude/skills/`. Не подключайте одновременно обе копии.

### Claude.ai / Cowork

Используйте plugin ZIP в интерфейсе загрузки пользовательского плагина, если он доступен в вашей среде. Для загрузки отдельного скилла используйте skill ZIP в настройках Skills/Capabilities. Доступность зависит от продукта и правил рабочего пространства; формат Claude Code не означает одинаковую доступность всех способов установки.

### ChatGPT

Для прямой загрузки скилла: Plugins → Skills → Create → Upload from your computer; выберите `ai-text-humanizer-0.1.1-skill.zip`. После проверки загрузки установите скилл и используйте его в новом чате. Функция доступна в поддерживаемых аккаунтах и может ограничиваться настройками рабочего пространства.

Для распространения полного плагина: plugin ZIP подготовлен как skills-only пакет для портала OpenAI. Публикация требует отдельной загрузки, заполнения карточки и проверки. Это не обещание прямой установки plugin ZIP в любой обычный чат.

### Codex

В пакете есть переносимый `plugin.json` и совместимый `.codex-plugin/plugin.json`, который указывает на `./skills/`. Установите пакет через поддерживаемый вашей версией интерфейс плагинов. Для локального использования одного скилла поместите папку `humanize-text` из skill ZIP в `.agents/skills/` проекта или `~/.agents/skills/` и начните новую сессию. Явный вызов:

```text
$humanize-text Отредактируй текст с учётом его типа.
```

Само клонирование этого репозитория не устанавливает скилл глобально.

## Сборка и проверки из исходного репозитория

Команды ниже выполняются из исходного репозитория, где есть scripts/ и tests/. Они не предназначены для распакованного runtime ZIP. Для сборки нужен Python 3.9+ без дополнительных пакетов:

```sh
python3 scripts/package.py
python3 -m unittest discover -s tests -v
```

В `dist/` появятся два архива: полный плагин и отдельный скилл. Сборка использует явный список файлов; исходники корпоративных проектов, оценки, тесты и локальная конфигурация в архивы не входят. В обоих архивах один и тот же скилл, без симлинков и внешних зависимостей.

[Источники и решения по совместимости](docs/sources.md). [Проверки и ограничения](docs/verification.md). Локальные проверки не равны фактической установке в Claude или ChatGPT.

## Происхождение

Использованы идеи `hrl-humanizer` и `docs-humanizer` из предоставленных пользователем локальных проектов: локальные регистры, проверка сохранности смысла, поиск неоднозначности, канцелярита и смысловых дублей. Инструкции адаптированы для разных жанров; корпоративные правила и пути не являются зависимостями пакета. Условия публичного распространения исходных наработок отдельно не устанавливались; лицензия третьих лиц этим репозиторием не переопределяется.
