# AI Text Humanizer

Плагин со скиллом `humanize-text` помогает писать и редактировать русский текст с учётом типа документа. Он работает со спецификациями, ADR, API-документацией, инструкциями, письмами, статьями, исследованиями, публичными и юридическими текстами. Если в одном документе соседствуют требования, инструкции и пояснения, скилл учитывает назначение каждого фрагмента.

Скилл можно использовать для написания, редактирования и ревью. При правке он сохраняет факты, условия, обязательность требований, технические литералы и голос автора. Первая версия оставляет английские фрагменты без изменений. Для работы скилла не нужны скрипты, MCP-сервер, ключи или внешние сервисы.

## Использование

Подключите скилл и опишите задачу обычным языком:

- «Очеловечь эту спецификацию. Сохрани REQ-ID и обязательность требований».
- «Напиши письмо коллеге по этим тезисам, на ты, без канцелярита».
- «Проверь статью на машинные штампы; верни только замечания, файл не меняй».
- «Отредактируй runbook.md, сохрани команды и автоматические действия сервиса».

Укажите тип документа или дайте скиллу выбрать профиль по задаче и содержанию. Если текст уже ясен, правки могут не понадобиться. Скилл не гарантирует обход детекторов ИИ и не заменяет проверку фактов или юридическую экспертизу.

Примеры на синтетических данных:

| Тип документа | Было | Стало |
|---|---|---|
| Описание процесса | В рамках подготовки к демонстрации аналитиком осуществляется проверка отчёта. Если в отчёте отсутствуют данные, аналитик направляет инженеру запрос на добавление данных и переносит демонстрацию. В случае успешного прохождения проверки демонстрация проводится в 15:00 | Перед демонстрацией аналитик проверяет отчёт. Если данных нет, аналитик просит инженера добавить их и переносит демонстрацию. Если проверка пройдена, демонстрация проходит в 15:00 |
| Спецификация | `REQ-12`. При наличии у пользователя права `EDIT` система должна осуществлять сохранение изменений. В отсутствие указанного права сохранение изменений не допускается. | `REQ-12`. Если у пользователя есть право `EDIT`, система должна сохранять изменения. Без права `EDIT` сохранение запрещено. |
| Письмо | Привет, Лена! Спасибо за помощь. В рамках подготовки встречи хотела бы попросить тебя прислать мне таблицу до четверга, если у тебя будет время. Если не получится, я перенесу встречу. | Привет, Лена! Спасибо за помощь. Если будет время, пришли мне, пожалуйста, таблицу до четверга: она нужна для подготовки встречи. Если не получится, я перенесу встречу. |
| Статья | Я приступил к чтению отчёта с уверенностью, что его объём является признаком полезности. Однако по завершении чтения двадцати страниц мной так и не был найден ответ на вопрос о причине переноса запуска. | Я начал читать отчёт, уверенный, что его объём говорит о пользе. Прочитал двадцать страниц, но так и не нашёл ответа: почему перенесли запуск? |

В первом примере сохранены исполнитель, обе ветви и время; убраны канцелярские обороты.

## Подключение

### Claude Code

Склонируйте репозиторий и запустите Claude Code из его корня:

```sh
git clone https://github.com/gyach/ai-text-humanizer.git
cd ai-text-humanizer
claude --plugin-dir .
```

В открытой сессии:

```text
/ai-text-humanizer:humanize-text Очеловечь переданный текст, сохрани смысл.
```

Манифест Claude находится в `.claude-plugin/plugin.json`, папка `skills/` обнаруживается автоматически. Чтобы подключить только скилл, распакуйте skill ZIP и поместите папку `humanize-text` в `.claude/skills/` проекта или `~/.claude/skills/`. Не подключайте одновременно обе копии.

### Claude.ai / Cowork

Если в вашей среде доступна загрузка пользовательских плагинов, загрузите plugin ZIP. Отдельный скилл загружается из skill ZIP в настройках Skills/Capabilities. Доступные способы подключения зависят от продукта и правил рабочего пространства; поддержка формата Claude Code сама по себе не гарантирует доступность каждого из них.

### ChatGPT

Чтобы загрузить скилл, откройте Plugins → Skills → Create → Upload from your computer и выберите `ai-text-humanizer-0.1.1-skill.zip`. После проверки загрузки установите скилл и начните новый чат. Загрузка доступна в поддерживаемых аккаунтах; настройки рабочего пространства могут её ограничивать.

Полный plugin ZIP подготовлен как skills-only пакет для портала OpenAI. Для публикации нужно отдельно загрузить его, заполнить карточку и пройти проверку. Прямая установка plugin ZIP в обычный чат не гарантируется.

### Codex

В пакете есть переносимый `plugin.json` и совместимый `.codex-plugin/plugin.json` с путём `./skills/`. Установите пакет через интерфейс плагинов, если ваша версия его поддерживает. Чтобы использовать только скилл локально, поместите папку `humanize-text` из skill ZIP в `.agents/skills/` проекта или `~/.agents/skills/` и начните новую сессию. Для явного вызова:

```text
$humanize-text Отредактируй текст с учётом его типа.
```

Само клонирование этого репозитория не устанавливает скилл глобально.

## Сборка и проверки из исходного репозитория

Запустите команды из корня исходного репозитория: им нужны папки scripts/ и tests/. В распакованном runtime ZIP этих папок нет. Для сборки достаточно Python 3.9+ без дополнительных пакетов:

```sh
python3 scripts/package.py
python3 -m unittest discover -s tests -v
```

В `dist/` появятся два архива: полный плагин и отдельный скилл. Сборщик включает только файлы из заданного списка. Исходники корпоративных проектов, оценки, тесты и локальная конфигурация в архивы не попадают. Оба архива содержат один и тот же скилл, без симлинков и внешних зависимостей.

Подробности — в разделах [Источники и решения по совместимости](docs/sources.md) и [Проверки и ограничения](docs/verification.md). Локальные проверки не подтверждают фактическую установку в Claude или ChatGPT.

## Происхождение

В основе — идеи скиллов `hrl-humanizer` и `docs-humanizer` из предоставленных пользователем локальных проектов: выбор регистра для отдельных фрагментов, проверка сохранности смысла, поиск неоднозначности, канцелярита и смысловых дублей. Инструкции переработаны для разных жанров. Пакет не зависит от корпоративных правил и путей. Условия публичного распространения исходных наработок отдельно не определялись; этот репозиторий не меняет лицензии третьих лиц.
